* 文件的处理
文件操作一般使用Dired
在我的配置中一般使用`C-x d`或者`C-f`去进行打开

而对于文件的操作，用以下列表来进行记录
注：这里我只记录我经常忘得
| 操作             | 快捷键            | 说明                 |
| 标记             | m                 | 标记当前文件         |
| 取消标记         | u                 | 取消当前标记         |
| 取消所有标记     | U                 | 取消所有的标记       |
| 查看文件         | v                 | 只读查看             |
| 可编辑Dired模式  | C-x C-q           | 进入可编辑Dired模式  |
| 重命名/移动文件  | R                 | Rename也可以进行移动 |
| 复制文件         | C                 | 输入目标路径Copy     |
| 关闭当前buffer   | C-x k             |                      |
| 重新加载当前文件 | M-x revert-buffer |                      |

| 左右分屏 | C-x 3  |
